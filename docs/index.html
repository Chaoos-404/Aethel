Conflicts

Explicit, never silent.

Keep local, keep remote, or keep both. Unrelated changes still go through.

!! notes/plan.md
both sides changed
Renames

A rename is a rename.

Folder moves are detected as moves, not deleted and uploaded again, even when files inside were edited elsewhere.

Recovery

Crash-safe commits.

Every completed operation is journaled. Run commit again and it picks up where it stopped, without replaying a single transfer.

Speed
20k

files diffed in about 80 milliseconds, over a shared pool of up to 40 parallel Drive connections.

Verbs you
already know.

If you know Git, you already know Aethel.

Review

aethel status           # local vs remote at a glance
aethel diff --side all  # both sides, in detail

Sync

aethel add -A           # stage suggested actions
aethel diff --staged    # review before applying
aethel commit -m "sync" # execute and checkpoint

One direction

aethel pull -m "pull"   # apply Drive changes
aethel push --dry-run   # preview uploads and deletes

Resolve

aethel resolve --keep local  file.md
aethel resolve --keep remote file.md
aethel resolve --keep both   file.md

History

aethel log --oneline    # compact sync history
aethel tag v1 HEAD      # name a snapshot

Maintain

aethel verify --remote  # hashes on disk and Drive
aethel clean --ignored  # dry run by default

Up and running
in three steps.

Requires Node.js 22.12 or later and a Google Cloud OAuth desktop client.

Step 1

Install

One global package gives you the aethel command.

npm install -g aethel
Step 2

Authenticate

Save credentials.json to ~/.config/aethel, then sign in.

aethel auth
Step 3

Clone

Bring a Drive folder, or all of My Drive, onto your machine.

aethel clone my-drive ./my-drive
aethel status

Get Aethel.
